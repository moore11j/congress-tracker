# SEC identifier enrichment for waiting institutional filings

November 26, 2026. Candidate on deployed `151c4d71`. Not deployed; revised exact CI and release review pending.

An existing source-owned filing with missing symbols could acquire a dated Massive mapping, but could not acquire a newly supplied, independently verified SEC N-PORT identifier. The ordinary new-filing path already accepts those SEC identifiers. The shared projection now allows missing-symbol enrichment from complete-original N-PORT rows filed by the target filing date. It evaluates the same dated legacy and SEC candidates through the existing resolver. Conflicts, unnormalized symbol drift, changed sources, published pairs and priors supporting published pairs retain their existing protections.

Only source-owned missing positions can be enriched. Reported CUSIPs, shares, values, dates and position identities stay unchanged. The receipt retains the exact N-PORT source hash, URL, row, symbol and filing date used. When that evidence disambiguates a Massive candidate, both proofs are retained. Repeating the evidence leaves the tested full state unchanged and sends no email.

The new corpus totals 52,115,168 bytes, exceeding the former 50 MB aggregate limit. File loading, shared staging and stored loading now use the same 60 MB aggregate bound. The 30 MB per-file limit, 50-document limit and publication-worker work/memory guards remain unchanged.

This is identifier qualification, not production publication recovery.
