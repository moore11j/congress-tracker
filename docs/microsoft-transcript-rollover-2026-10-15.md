October 15, 2026 UTC. Implementation and isolated validation; not yet deployed at this checkpoint.

## Gap and behavior

The eight-issuer registry previously discovered future periods only for Reddit. Microsoft and six other issuers used fixed reviewed links. A working current-quarter transcript therefore did not establish unattended future-quarter coverage.

The reviewed [Microsoft investor home page](https://www.microsoft.com/en-us/investor/default) links its completed earnings event separately from the upcoming earnings announcement. The event-list page did not expose suitable server-rendered event links and is not used. No inferred next-quarter URL, notification link or arbitrary fetched host grants source permission.

The new Microsoft policy accepts exact official event paths and matching fiscal years/quarters. Its June fiscal year-end is explicit: FY2027Q1 ends September30,2026. The transcript independently proves fiscal identity, heading publication date and Q&A. Dates outside the completed fiscal period's100-day window, future publications, missing Q&A and inconsistent identities remain held. A newly discovered pending period prevents silently serving the older quarter.

The existing collector shares its two-page/run limit across Reddit indexes/PDFs, the Microsoft index/event and static documents. It reserves each attempt before network access, releases transactions during HTTP, rechecks no more than daily and excludes removed policies. No trigger, limit or host change. Microsoft's current statically reviewed period keeps its original metadata/proof. New periods pin immutable index revisions; harmless later index changes do not rewrite that evidence. Existing research reconciliation, explicit publication boundary and cross-provider duplicate checks remain required. Transcript selection remains FMP.
