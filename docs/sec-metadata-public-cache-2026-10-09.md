# Public metadata cache at source activation

October10UTC: direct API and proxy checks returned SEC company fields after the approved selector change, but the browser still rendered the old FMP sector and industry. The anonymous SSR fetch retains a 24-hour Next data cache across deployments. The context request version had not changed with metadata semantics, and the fallback profile request had no version at all.

Version 13 now applies to both context and fallback profile URLs, so both fetch current selected metadata. Cache TTLs, public rendering, authentication partitioning and entitlement projection remain intact. This is a release cache invalidation, not a new source fetch or ranking rebuild. Browser verification after deployment remains required.
