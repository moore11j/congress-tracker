# Current quote in the ticker header

The owner reported that NBIS still showed yesterday's price. The price feed was updating, but the mobile header called the daily price-volume summary's `latest_close` the latest available price. At22:53UTC, the public quote and context endpoints returned84.5942 observed November20 22:33UTC, while the daily chart correctly held96.92 through November19. The prior incident verification did not establish a current-quote header; this repairs that remaining presentation defect.

The candidate reads the existing lightweight public cached quote endpoint, seeded by the page's existing context quote. It displays the actual observed date/time in Eastern time, source delay and current quote's own daily change. It refreshes once per minute while visible, coalesces requests, aborts after ten seconds and cleans up on navigation/unmount. It bypasses the anonymous server-page cache without adding another context-bundle request. Missing, invalid, wrong-symbol, undated, future or older observations fall back to an explicitly dated daily close. Refresh failure retains an identified last available quote with a warning and suppresses its change percentage.

The same header is visible on mobile and desktop. Daily volume remains separately dated. The lower technical card is labeled daily close, and daily chart statistics show their completed session date. No daily chart bar is replaced with an intraday quote, and historical returns, scoring, source selection and entitlements remain unchanged.

The existing end-of-day readiness rule is18:00 America/New_York. The daily chart advanced ordinarily to November20 after that boundary.
