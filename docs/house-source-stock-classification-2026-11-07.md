# Source-bound House common-stock classification

The November 7 read-only publication audit found six House filings held by shared security labels. Four contain NVIDIA common-stock rows while the shared NVDA record says `Stock Option`. One contains Prologis common stock while its shared PLD record says `REIT`. The remaining filing contains an investment fund. Two Senate backup filings have separate ETF conflicts and are outside this repair.

Six complete official House PDFs were downloaded and matched byte-for-byte to their stored SHA-256 receipts, totaling 481,340 bytes. Five originals explicitly identify the affected instrument as `Common Stock`, include the matching ticker and declare stock rows. The exact original parser returns 19 transactions across these five filings, including seven NVDA and two PLD rows affected by the old shared labels. Source row numbers preserve separate equal-value lots. The fund filing remains held in full.

The publisher accepts this narrow evidence only for an official House row parsed with the current row parser, an explicit stock classification, a complete common-stock description with the exact ticker, and an issuer name matching the existing security name after case/punctuation normalization. Only the existing `Stock Option` and `REIT` labels qualify. Unknown, fund, ETF, bond, option, amended, inconsistent-name, mismatched-ticker and unverified-parser cases remain held. There is no ticker allowlist.
