# Free SEC ratio preparation, October 9

This implements the owner's free-first sequence without activating core fundamentals or requesting Massive data. A separate opt-in job prepares SEC-derived ratios in an isolated InsightsSnapshot namespace. The existing FMP fundamentals cache, public selection, prices, scores and recorded history stay unchanged. No new schema column is required by this preparation release.

The actual existing projector verifies ticker/CIK identity, USD US GAAP units, aligned trailing periods and completed New York filing dates. It provides up to ten metrics: margins, revenue growth, margin expansion, current ratio, return on average equity, free cash flow and FCF growth/margin. It makes no market requests, fills no estimates/targets/EBITDA proxies, and does not pretend unsupported issuers have neutral financial evidence. Supported coverage remains explicitly partial. Directory absence, verified company-facts404 and unsupported current periods are cached as unavailable; mismatched identity and transient refusals do not become valid ratio caches.

Preparation uses twenty-four-hour caches, five oldest-attempted symbols per run, the shared SEC collector lock, a bounded warming lease, background-pressure guard and refusal stop. Company/facts requests finish before the ratio-cache write transaction; that transaction has statement/lock/idle timeouts. Source hashes, period inputs, accession numbers and calculation formulas accompany the metrics. This evidence is separate from current canonical financial records and eventual Massive price/market-cap observations.

Thirty focused tests pass on Python3.14.2, covering actual ratio calculations, repeat without new transport, absence/refusal/identity handling, failed refresh preservation, selected-provider guards, warming overlap/rotation and existing financial comparisons. An initial fixture used the reserved UNKNOWN symbol and was corrected to a valid absent ticker; no normalization rule changed.
