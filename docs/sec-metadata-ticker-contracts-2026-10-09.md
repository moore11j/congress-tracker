Cached ticker context responses could also retain legacy sector/industry fields after selection. This follow-up routes those identity fields through the selected prepared source and overlays a copy of cached responses before entitlement projection. It preserves quote values, score evidence and the original cache for rollback.

Public ticker headers explicitly label the industry as SEC SIC. The profile memory-cache key includes the metadata provider. Public metadata reads remain cache-only; this change does not select metadata or change prices.
